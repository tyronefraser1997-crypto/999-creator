999 CREATOR

Privacy Policy

Last updated: 5 November 2026

999 Creator is a personal Windows desktop application that converts locally stored audio files and artwork into vertical MP4 videos.

1. Information We Process

The current application processes audio files, embedded metadata, artwork, and video files selected by the user.

2. Local File Processing

Video creation takes place locally on the user's computer. Original audio files are not modified by the video creation process.

3. TikTok Integration

TikTok account integration is under development and is not currently available in version 1.6. Any future integration will require user authorisation and will be subject to TikTok's applicable developer requirements.

4. Data Sharing

The current video creation functionality does not automatically upload selected audio files or generated videos to TikTok.

5. Security

Users should protect access to their computers and locally stored files. Any future TikTok integration will be designed to use official account authorisation rather than requesting TikTok account passwords.

6. Policy Updates

This policy may be updated as the application develops, particularly if new account connection or publishing functionality is introduced.

7. Contact

Questions about this policy can be submitted through the project's GitHub Issues page .
