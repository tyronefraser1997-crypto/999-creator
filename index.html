Windows Desktop Application

Create music videos.
The 999 way.

999 Creator is a personal Windows desktop application designed to transform locally stored audio and artwork into vertical MP4 videos.

Music Recognition

Read available song titles, artist information and embedded artwork from audio files.

Video Creation

Convert audio and cover artwork into vertical MP4 videos with progress tracking.

TikTok Integration

Official TikTok integration is being investigated for a future version. It is not currently available.

Development status

Version 1.6 is a locally operated Windows application. Version 1.7 is in the planning stage. TikTok publishing functionality is subject to platform approval.
